# Skill Content Spec

Each published Skill should be safe, readable, and portable across AI coding agents.

## Folder Shape

```txt
[slug]/
  SKILL.md
  references/
    style-dna.md
    layout-patterns.md
    component-rules.md
    motion-rules.md
    example-prompts.md
  LICENSE.txt
```

## SKILL.md Requirements

- Trigger description.
- Best-fit use cases.
- Core aesthetic direction.
- Prohibited defaults and anti-patterns.
- Layout, typography, color, component, and motion rules.
- Code preferences.
- Output checklist.

## Safety Rule

MVP Skills are Markdown only. They contain no scripts and make no external requests.
