```txt
/en/changelog
/zh/changelog
```

## Primary Flow

1. User lands on the home page.
2. User browses styles or opens same-prompt comparison.
3. User opens a style detail page.
4. User checks landing, dashboard, and settings previews.
5. User downloads the Skill or reads install docs.

## Navigation

Top navigation links to Styles, Compare, Install, Request, and language switch. Preview pages have a compact utility bar that links back to the English style detail page and the Skill download.
