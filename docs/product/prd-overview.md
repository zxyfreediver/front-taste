# FrontTaste PRD Overview

FrontTaste is a preview-first gallery of frontend style Skills for AI coding agents. Users browse real visual outputs, choose an aesthetic direction, then download a reusable Skill that guides future AI-generated frontend work.

## Positioning

- English: Preview frontend taste before installing the Skill.
- Chinese: 先看审美，再装 Skill，让 AI 按你喜欢的风格写前端。
- Category: curated frontend style Skills with visual previews.

## Audience

- AI coding users working with ChatGPT, Codex, Claude Code, Cursor, Windsurf, v0, Lovable, Bolt, and similar tools.
- Indie developers building SaaS landing pages, product sites, waitlists, dashboards, admin panels, pricing pages, and portfolios.
- Frontend engineers and design engineers who want reusable style constraints instead of rewriting prompts.

## Core Problem

Frontend Skills are visual products, but most Skill directories only show README files and install commands. Users need to see landing pages, dashboards, and settings screens before trusting a style Skill.

## Product Boundary

FrontTaste is not a live AI UI generator, template marketplace, generic prompt library, account system, paid UI theme store, or Figma plugin. It is a curated shelf of reusable frontend taste for AI coding agents.
