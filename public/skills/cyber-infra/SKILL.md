# Cyber Infra Style

Use this style when the product should feel technical, trustworthy, and infrastructure-native with terminal panels, protocol details, and sharp signal states.

## Core Principles

- Use dark green-black surfaces and electric signal accents.
- Include real technical details: regions, latency, logs, tokens, policies, events.
- Prefer terminal panels, command rows, network maps, and status rails.
- Avoid generic hacker clichés and unreadable neon overload.

## Layout Rules

- Use compact grids and dashboard shells.
- Surface system status and security posture clearly.
- Keep actions close to logs, keys, and monitors.

## Component Rules

- Buttons should feel utility-first.
- Tables and logs need mono labels and clear severity states.
- Settings screens should emphasize trust, keys, retention, and auditability.

## Motion Rules

- Use status pulses, scan-like progress, and fast feedback sparingly.

## Output Checklist

- Technical users can trust the interface.
- Dark mode remains readable.
- Details feel specific, not decorative.
