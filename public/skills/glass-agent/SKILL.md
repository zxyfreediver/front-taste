# Glass Agent Style

Use this style when the product should feel AI-native, layered, lightweight, and precise without becoming generic glassmorphism.

## Core Principles

- Use translucent layers only where they clarify depth and state.
- Prefer cool blue surfaces, crisp borders, and readable contrast.
- Show agent behavior through timelines, tool calls, queues, and result states.
- Avoid blurry low-contrast text and decorative floating panels.

## Layout Rules

- Use stacked panels for agent context, tools, and outputs.
- Keep the main task area visually dominant.
- Let assistant messages and tool calls have distinct anatomy.

## Component Rules

- Buttons should feel precise and modern.
- Cards need enough contrast against translucent backgrounds.
- Status indicators should show agent progress clearly.

## Motion Rules

- Use light reveals, progress transitions, and depth changes.
- Respect reduced-motion preferences.

## Output Checklist

- Text stays readable over every glass surface.
- Agent state is understandable.
- Depth supports the workflow instead of becoming decoration.
