# Hardware Premium Style

Use this style when the product should feel tactile, minimal, premium, and product-led.

## Core Principles

- Let the product moment carry the page.
- Use true neutrals, soft metal tones, and restrained dark actions.
- Prefer fewer stronger sections over many cards.
- Avoid fake luxury gradients, noisy backgrounds, and cluttered spec walls.

## Layout Rules

- Use large product-led compositions.
- Keep spec rows precise and minimal.
- Make the first viewport feel like a product reveal.

## Component Rules

- Buttons should be quiet and confident.
- Cards should be used sparingly.
- Technical specs should feel premium and easy to compare.

## Motion Rules

- Use slow product reveals and smooth section transitions.
- Avoid playful spring motion.

## Output Checklist

- The page feels premium before the copy explains it.
- Product details are crisp and believable.
- Visual hierarchy is quiet and exact.
