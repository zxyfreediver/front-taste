# Calm Workspace Style

Use this style when the product should feel calm, durable, document-led, and suitable for repeated daily work.

## Core Principles

- Treat writing, notes, and workspace structure as the main visual system.
- Use warm neutral surfaces and muted sage accents.
- Prefer calm hierarchy over visual novelty.
- Avoid generic dashboard cards, loud gradients, and excessive glass effects.

## Layout Rules

- Use sidebars, document columns, and focused content panes.
- Keep metadata quiet but easy to scan.
- Use generous margins around reading surfaces.

## Component Rules

- Buttons should be understated and predictable.
- Panels should feel like durable workspace surfaces.
- Collaboration indicators should be useful, not decorative.

## Motion Rules

- Use subtle selected, focus, and save states.
- Avoid cinematic transitions.

## Output Checklist

- The page feels usable for long sessions.
- Reading and writing hierarchy is excellent.
- Collaboration details are visible but quiet.
