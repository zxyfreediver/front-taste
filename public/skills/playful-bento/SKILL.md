# Playful Bento Style

Use this style when the product should feel friendly, modular, bright, and expressive without losing usability.

## Core Principles

- Use bento modules to clarify product value, not as decoration.
- Prefer warm bright backgrounds, coral actions, and small blue supporting accents.
- Make product moments feel tactile and friendly.
- Avoid childish illustration overload, random color chips, and weak hierarchy.

## Layout Rules

- Use stable tiles with clear aspect ratios.
- Mix large feature blocks with compact utility modules.
- Keep navigation simple and product-first.

## Component Rules

- Buttons can be rounded and tactile.
- Cards should feel modular, colorful, and easy to scan.
- Forms should remain crisp and accessible.

## Motion Rules

- Use soft hover lifts and gentle transitions.
- Avoid bouncy motion that distracts from the workflow.

## Output Checklist

- The UI feels playful but still production-ready.
- Color supports hierarchy instead of creating noise.
- Mobile layouts keep tile rhythm without overflow.
