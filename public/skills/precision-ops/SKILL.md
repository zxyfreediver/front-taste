# Precision Ops Style

Use this style for dense product operations, admin panels, team analytics, status surfaces, filters, tables, and production-like dashboards.

## Core Principles

- Prioritize scan speed, alignment, and explicit state.
- Use compact spacing without crowding text.
- Prefer tables, rows, filters, split panes, and status badges over decorative cards.
- Make every metric feel actionable.

## Layout Rules

- Use side navigation, filter bars, summary rows, and table-first layouts.
- Keep controls predictable and close to the content they affect.
- Use sharp but not harsh borders.

## Component Rules

- Tables need clear headers, row rhythm, status states, and right-aligned numeric columns.
- Buttons should use concise labels and small icons.
- Empty, loading, and error states should look operational, not playful.

## Motion Rules

- Prefer fast hover, focus, and selected-state feedback.
- Avoid cinematic transitions.

## Output Checklist

- A user can scan the important metric in under three seconds.
- Dense screens do not collapse into card soup.
- Mobile views preserve task priority.
