# Neon Cyberpunk Style

Use this style when the product should feel like a night-city command HUD: high energy, technical, and game-like.

## Core Principles

- Use a dark base with cyan rails, hot pink actions, and violet panel depth.
- Make panels feel like HUD instruments rather than normal cards.
- Convert product states into operator states: risk level, sync status, target owner, signal strength.
- Keep neon controlled; contrast and readability are more important than glow.

## Layout Rules

- Use angled panels, clipped corners, scanline overlays, radar blocks, and command strips.
- In dashboards, use dense status grids, risk feeds, and mission telemetry.
- In settings, use system modules, authorization rows, retention locks, and access levels.
- Avoid soft pastel SaaS cards, casual illustration, and excessive decorative clutter.

## Component Rules

- Buttons can be neon-filled, outlined, or slanted.
- Use uppercase mono labels for status and metadata.
- Tables should feel like command logs with sharp active rows.
- Progress states can use signal bars, pulses, and radar rings.

## Motion Rules

- Use fast scanline reveals, electric hover states, and restrained pulses.
- Avoid slow cinematic motion or springy playful effects.

## Output Checklist

- The UI reads as a game HUD before reading any label.
- Neon is visible but does not reduce legibility.
- At least one radar, signal, command, or scan motif appears.
