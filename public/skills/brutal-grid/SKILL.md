# Brutal Grid Style

Use this style when the product should feel direct, memorable, and design-forward with hard borders, visible grids, oversized type, and strong contrast.

## Core Principles

- Use exposed borders, hard modules, and asymmetric grid composition.
- Prefer blunt copy, large type, and high-contrast states.
- Avoid soft SaaS gradients, glass effects, and overly polished luxury cues.

## Layout Rules

- Use visible grid lines and clear modules.
- Let one or two elements break symmetry.
- Keep the hierarchy loud but controlled.

## Component Rules

- Buttons can use offset shadows and strong borders.
- Cards should feel like modules, not soft containers.
- Tables and settings screens can use terminal-like or print-like structure.

## Motion Rules

- Use immediate hover offsets and sharp state changes.
- Avoid slow fades.

## Output Checklist

- The page is readable despite strong contrast.
- Borders and shadows are consistent.
- The design feels intentional, not broken.
