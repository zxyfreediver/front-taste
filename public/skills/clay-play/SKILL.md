# Clay Play Style

Use this style when the product should feel friendly, touchable, playful, and still production-ready.

## Core Principles

- Use inflated rounded panels, thick soft shadows, pastel colors, and tactile controls.
- Make the UI feel like soft product objects, not flat cards.
- Keep labels and metrics clear so playfulness does not reduce usability.
- Prefer warm delight over childish decoration.

## Layout Rules

- Use chunky modules, pill dashboards, soft stacked cards, and playful staggered layouts.
- In dashboards, use large rounded metrics and plush progress controls.
- In settings, use big toggles, soft grouped panels, and friendly confirmation states.
- Avoid sharp technical grids, black-white severity, and dense admin tables.

## Component Rules

- Buttons are rounded, thick, and pressable.
- Badges can be soft capsules or small clay tokens.
- Cards should have visible depth and soft 3D weight.
- Charts should be simplified into friendly blobs, pills, or chunky bars.

## Motion Rules

- Use tactile press, soft lift, and gentle scale transitions.
- Avoid harsh snaps, glitches, and high-speed effects.

## Output Checklist

- The UI feels touchable in the first viewport.
- Rounded 3D depth appears in core components.
- The page is playful but not unserious.
