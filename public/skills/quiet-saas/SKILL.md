# Quiet SaaS Style

Use this style when the user wants restrained, production-ready SaaS UI with generous whitespace, muted neutrals, precise hierarchy, subtle motion, and non-generic AI product aesthetics.

## Core Principles

- Use generous whitespace and clear vertical rhythm.
- Prefer muted neutral backgrounds with one restrained green accent.
- Avoid loud gradients, oversized emoji, and generic purple AI hero sections.
- Make every section feel intentional and useful, not decorative.
- Use product-specific details: meetings, tasks, permissions, billing, metrics, and onboarding states.

## Layout Rules

- Use centered max-width containers for marketing pages.
- Use quiet grids and aligned baselines for product UI.
- Use bento layouts only when they clarify product value.
- Avoid excessive stacked cards and oversized rounded wrappers.

## Component Rules

- Buttons should feel precise and quiet.
- Cards use subtle borders and soft shadows.
- Tables should be readable and production-like.
- Forms should feel trustworthy, minimal, and calm.

## Motion Rules

- Use subtle fades, slides, and scale only when they clarify interaction.
- Avoid floating decorative elements.

## Output Checklist

- The first viewport states one product promise.
- The palette is restrained and not purple-gradient generic.
- Landing, dashboard, and settings screens feel like the same product.
- Text fits on mobile and desktop.
