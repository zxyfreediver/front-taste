# Vintage Computing Style

Use this style when the product should feel like a trustworthy classic desktop tool.

## Core Principles

- Use beige hardware colors, inset panels, old menu bars, and terminal surfaces.
- Treat the app as a desktop utility with windows, status bars, and compact controls.
- Use nostalgic details without making the product hard to use.
- Prefer durable system charm over parody.

## Layout Rules

- Use window chrome, title bars, menu rows, terminal blocks, and status strips.
- In dashboards, show metrics as utility windows and command outputs.
- In settings, use dialog boxes, checkboxes, beveled buttons, and system panels.
- Avoid modern glass, giant gradients, and soft SaaS cards.

## Component Rules

- Buttons are beveled rectangles or old dialog actions.
- Badges can look like file labels, drive names, or terminal prompts.
- Tables should resemble system logs.
- Use amber or green terminal text for technical panels.

## Motion Rules

- Use simple selected states and cursor-like feedback.
- Avoid modern microinteraction polish that breaks the retro desktop illusion.

## Output Checklist

- The interface reads as vintage computing before reading the style name.
- Window chrome and terminal details are visible.
- The layout still works as a modern product screen.
