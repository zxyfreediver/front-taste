# Dense Analytics Style

Use this style for serious data products where users need to compare, filter, and act quickly.

## Core Principles

- Prioritize information density, alignment, and comparison.
- Use compact mono metrics and table-first hierarchy.
- Prefer deep navy surfaces with restrained blue data highlights.
- Avoid sparse marketing layouts and oversized KPI cards.

## Layout Rules

- Use metric grids, filter rows, split charts, tables, and side panels.
- Align numbers and columns carefully.
- Keep controls close to the data they modify.

## Component Rules

- Tables need clear headers, row states, and numeric alignment.
- Charts should be readable and not purely decorative.
- Filters should be compact and visible.

## Motion Rules

- Use fast state updates.
- Avoid heavy animation that slows analysis.

## Output Checklist

- Dense screens remain readable.
- Users can compare metrics quickly.
- Empty, loading, and error states are production-like.
