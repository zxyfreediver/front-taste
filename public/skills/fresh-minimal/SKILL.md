# Fresh Minimal Style

Use this style when the product should feel clean, modern, breathable, and immediately useful.

## Core Principles

- Use whitespace as a primary design material.
- Keep color pale and restrained, with one confident green or blue-green action color.
- Favor thin lines, calm cards, and clear hierarchy.
- Remove visual noise unless it directly helps comprehension.

## Layout Rules

- Use large open sections, simple grids, calm summary cards, and generous spacing.
- In dashboards, use thin dividers, readable metrics, and low-density comparison rows.
- In settings, use quiet grouped controls, minimal labels, and clear save states.
- Avoid dense admin patterns, heavy shadows, loud gradients, and novelty decoration.

## Component Rules

- Buttons are rounded but not cute; use confident fill for primary actions.
- Badges are subtle pills or inline labels.
- Forms should feel simple, trustworthy, and spacious.
- Charts should be light and easy to scan.

## Motion Rules

- Use soft fades and tiny hover lifts only.
- Avoid playful bounces, neon pulses, and heavy transitions.

## Output Checklist

- The page feels fresh and calm in the first viewport.
- Every section has room to breathe.
- The UI is clearly more than a default white SaaS template.
